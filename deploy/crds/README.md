# Upstream-generated CRDs

These 11 definitions were generated by the digest-pinned Michelangelo API server
0.11.0, matching upstream Git revision
`37852aace4dd9f9658c11c19c56d19692ac5d2c4`. Runtime cluster metadata and status
were removed. The post-renderer verifies their aggregate SHA256 before use.

The upstream chart's namespace-scoped RBAC does not allow its API to register
CRDs, and the pinned controller does not implement namespace-scoped watches.
This wrapper installs the definitions using the operator's deployment authority
and disables runtime CRD synchronization. It removes CRD mutation privileges
from the application ClusterRole. Use a dedicated OKE cluster.

Helm keeps these definitions on uninstall to avoid silently deleting all custom
resources. A disposable Terraform cluster teardown removes the entire cluster.
For a persistent cluster, review all CR instances before manually removing CRDs.

`tools/bootstrap_crds.py` is a development regeneration helper. It temporarily
grants only CRD get/list/create/update/patch permissions to the pinned API server,
exports definitions, and removes the temporary role/binding. Regeneration is a
source upgrade operation: review schema changes and update the checksum only
after compatibility checks. Ordinary customers do not need to run this helper.
